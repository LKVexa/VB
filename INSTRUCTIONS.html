VB / SOURCE + PORTABLE + COMPILER

Your quick instructions

Join the parts. Open VB. Rebuild whenever you need.

1

Download and join

Save every numbered ZIP part and START-HERE.zip together. Extract START-HERE.zip, then open Join VB Parts.cmd. It checks, joins and extracts the kit. Open the kit inside VB-JA21-4.8.0-Kit-Ready. Keep about 2 GB free.

2

Check and run

Open Verify Kit.cmd. When it passes, open Run VB.cmd. The portable browser is already built.

3

Edit and compile optional

Close VB. Edit the files in VB/source, then open Compile VB.cmd. Wait for the success message. The JA21 compiler and required Python/Node runtimes are included.

4

Build an installer optional

Open Build Installer.cmd. Find the result in Builds. This step also needs the Windows .NET Framework 4 compiler and WPF libraries; those Windows components are not bundled.

5

Recover from a problem

If a part is missing or changed, download that part again. Do not rename parts or extract them individually. Existing extracted folders are kept; use a fresh folder to retry.

Before you begin
Each full part is 24,000,000 bytes; the last is smaller. Portable data lives in VB/profile. Close older VB/Air Glass instances first. DeleteMe permanently removes the locations in its review; keep any wanted data before confirming.
